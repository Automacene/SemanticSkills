Skill Designer

skills.automacene.org/v1alpha1
Identity
Authors

npm's form. A name, an optional <email>, an optional (url). Only the name is required.

Capabilities

What this implements, in taxonomy terms. A public node cites its id; a private one is prefixed with your domain and has none.

Inputs

A default is a value substituted for the input. It is a different thing from a section's default, which replaces the section entirely. An input with a default can never be missing, so it cannot also be required.

Test value is not part of the document. It is what the filled prompt uses.

Sections

Ordered. A section falls back to its default text when any input it uses comes back empty. Exactly one section is the input.

Output

Optional. With none, the skill returns a single implicit text field.

Settings

The author's suggestion, measured where the skill was written. A caller overrides any of it.
